# Forgetcase — User stories

**Product:** [PRODUCT.md](./PRODUCT.md)


### Privacy caseworker

- As a caseworker, I want guided ground-and-exemption checks, so that I do not erase when a legal claim exemption applies.
- As a caseworker, I want the calendar-month deadline computed correctly across short months, so that ICO timing examples are met.
- As a caseworker, I want backup beyond-use status on the case, so that I can explain honestly what happens to the individual’s data.

### Frontline support agent

- As a support agent, I want to log a verbal forget request in under two minutes, so that any employee channel works.
- As a support agent, I want confirmation read-back of the request, so that later disputes about interpretation are reduced.

### Records / backup owner

- As a records manager, I want tasks to place backup copies beyond use, so that live deletion is not falsely treated as complete.
- As a records manager, I want overwrite schedule visible on the case, so that communications stay accurate.

### Children’s product owner

- As a children’s product owner, I want cases involving child-collected data escalated, so that enhanced weight is not optional.

### DPO / legal

- As a DPO, I want refusal packs with mandatory notices, so that refusals themselves are compliant.
- As legal counsel, I want to record DPA 2018 exemption reliance, so that UK-specific bases are evidenced.
- As a DPO, I want an exception when ID demands look disproportionate, so that we do not unlawfully delay.
